#PhiEdit-Mobile  现已正式投入开发


##应用介绍
PhiEdit-Mobile是一款可以让各位谱师在手机上就能实现创建，编辑和预览一体化的自制谱编辑工具

该应用旨在让用户拥有更好的做谱体验的同时，顺带填补Android做谱应用的空白
（毕竟Android可用的只有TPhi Editor一个。。。）

##当前计划:

###2.初步完成UI和对Kotlin编程语言的学习和使用
###3.初步完成对应用图标的设计

该软件目前不打算设计限制传播，我做这个的初衷是为了让更多人可以做谱
而不是希望看见工具被垄断和创意被卡的现象……
